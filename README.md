## テスト版 #107：履歴の支出合計・クーポン使用（2026-11-04）

対象は money-keeper-test のみ。本番版1.0・Miniは更新しません。基準コードはテスト版#106です。

### 変更内容

- 記録履歴の検索・絞り込み後、一覧の上に支出合計と表示件数を表示。0件は0円。条件解除・編集・削除でも再計算します。
- 期間選択に「今日」を追加。日付は端末の現地日付。メモ・相手・グループ名・種類・カテゴリ・支払方法・特別費など、一覧に適用された条件と同じ対象を集計します。
- 合計は既存の支出集計と共通。支出・私が立替・相手が立替・グループ会計の自分の負担額からポイントとクーポンを控除し、対象の手数料を加算。入金・資金移動・チャージ・貸付・借入・清算の元本は含めません。
- カテゴリで絞った場合も、表示された記録全体の支出額を合計します。複数カテゴリの一致部分だけの合計ではありません。その旨を合計欄に表示します。カテゴリ単体の集計は従来の集計画面を利用できます。
- 引落時のカード割引は従来どおり請求額へ反映し、支出集計の扱いは変更しません。過去の立替ポイント要確認記録は暫定額を維持し、合計欄にも注意を表示。
- ポイント使用／クーポン使用を小さい見出し付きで1行2枠に配置。新規・通常編集・グループ編集に対応。金額は円換算、¥とカンマ表示。新規の空欄は0扱い、クリア時は空欄。
- ポイント・クーポンは別項目で保存し、計算時は合算。支払額・残高・請求額・カテゴリ按分・月別/特別費集計へ反映。履歴にも別々の使用額を表示します。
- 個人立替では合計が自分の負担額を超えないこと、グループでは自分の支払額・負担額の小さい方までであることを検証。参加者の値引き前内訳や清算残額のルールは維持。
- 「相手が立替」など、従来ポイントを計算に使わない記録にはクーポンも適用しません。今回の追加はポイントと同じ対象・ルールです。

### 保存と更新
