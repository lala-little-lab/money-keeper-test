# Money Keeper 本体テスト版 #92

## #92 口座・支払方法の管理①（2026-10-30）

基準：本体テスト版#91。対象ZIP：MK_test_092_261030_Settings_Manager.zip。

### 入口と操作
- ホーム「残高」横の歯車から、口座・残高／支払方法／カード・引落／ボタン配置の4枚のカードを開く。「その他」のカード数は増やさない。
- 設定は下書きで編集。項目の「設定に反映」は下書きに戻す操作で、最後の「保存」で端末に反映する。「編集を戻す」は項目の未反映編集を破棄。「キャンセル」は設定画面全体の変更を破棄。
- 保存前に形式・参照先・重複・配置の欠落を検査。保存中の操作を止め、端末への保存成功後に表示へ反映。保存失敗時は変更前の実データを保ち下書きを残す。

### 名前と表示
- 口座・残高：名称変更、ホーム残高欄の表示／非表示、新しい記録の候補への表示／非表示、右端つまみの長押し並べ替え。
- 支払方法：名称変更、新しい記録の候補の表示／非表示、右端つまみの長押し並べ替え。上下キーでも移動可。
- ホーム非表示と候補非表示は別設定。隠した残高も手元資金合計に含める。残高合わせでは全口座を選べる。
- 候補非表示は新規記録の支払・入金・やりとり、資金移動の口座、チャージ先・元、楽天Pay支払元へ適用。既存取引の編集候補と履歴の検索候補には情報を残す。既存の定期支払い・請求計算は停止しない。
- 非表示でも既存の残高、記録、貸し借り、カード請求、引落口座との紐付けは削除しない。管理画面の「非表示の項目」から編集して再表示できる。
- 保存時、入力途中の支払元などが非表示になった場合は選択だけ解除。金額・メモなどの入力は保持。非表示のチャージ既定元を自動選択しない。楽天Payの表示可能な支払元が0件の場合は新規登録を止め、候補の再表示を案内。
- 口座名と支払方法の短いボタン名は個別に編集する。口座名変更はホーム・口座選択・カード請求の引落口座名に、支払方法名変更は対応する支払候補とカード名に反映。
- IDで参照する過去の履歴表示にも新しい名前を反映する。過去の自由記述メモ・通帳の文章・定期支払いの経路文章等は書き換えない。旧名称の別名情報と経路解釈を保ち、紐付けを変更しない。
- 名称は1〜60文字（前後の空白を除去）。同じ一覧内の同名、制御文字、< >を拒否。

### ボタン配置
- 支出・やりとりで共通の「いつも表示」「もっと見る」、入金先、チャージ元を編集。
- 各行1〜4個で指定し、右端つまみで順番変更。支払方法は「もっと見るへ／いつも表示へ」で区分移動。「もっと見る」ボタンは常時表示側の1枠として順番変更可能。
- 個数変更では順番を保ち、続きの行へ配置。残った項目は最大4個ずつの行へ送る。非表示項目の元の配置を保持し、表示時は行内の見える項目を均等幅にする。
- プレビューで配置を確認できる。従来の配置は設定を操作するまで保持。入金先の従来の短い最終行も、入金配置を編集するまでは保持し、編集後は均等幅へ変更。
- 管理画面「支払方法」の並べ替えは、いつも表示ともっと見るを連結した項目順を入れ替え、現在の各行の枠数を維持する。「もっと見る」の位置は維持。

### カードと今回の範囲
- カード・引落カードでは、現在のカード名・締め日・翌月引落日・引落口座を確認する。
- 新規追加・削除・支払元変更・締め日変更・引落口座変更は今回未実装。次の②口座・電子マネー追加、③カード追加・紐付け変更で扱う。
- 楽天Edy追加、複数人立替、外貨入力、チャージボタン太字調整、定期支払いの未完成紐付けの完成は対象外。
- 「引落口座の準備」の未登録案内は#82〜#91からの固定表示で、今回のデータ消失ではない。今回も変更しない。

### 保存・バックアップ
- schemaVersion 2、mkSettings.version 1を維持。追加の表示情報はmkSettings.uiに保存（hiddenBalances／hiddenPays／payOrder／customIncome）。項目がない#89〜#91のバックアップも受け入れる。
- 設定はJSONバックアップ対象。書き出し名MK_YYYYMMDD_HHmmss.jsonを維持。イベント固定ON/OFFの従来の別保存は変更しない。
- 内部ID・口座やカードとの紐付け・金額は変更せず、既存の記録を再実行しない。
- #92で設定を保存したJSONを旧版が読めることは保証しない。更新前のバックアップは保持し、新しいアプリで運用する。
